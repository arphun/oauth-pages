Privacy Policy

Last updated: 2026-11-20

batch_testbed ("the app") is a private, single-user tool. Its only user is its owner. This policy describes how the app handles Google user data.

Data the app accesses

With the owner's permission (Google Drive scope), the app reads and writes files in one Drive folder that the owner designates: task folders, prompt and configuration files, input images, flag files, and generated output images. It does not read the owner's other Drive content, and it does not access Gmail, Contacts, Calendar or any other Google service.

How the data is used

  • Prompts and input images from the task folder are sent to image-generation models to produce output images.
  • Generated images and completion markers are uploaded back to the same Drive folder.
  • Files are cached temporarily on the owner's own workstation while a task runs.

Sharing

Google user data is not sold, not used for advertising, and not shared with third parties beyond the image-generation processing described above. No analytics or tracking are used.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

The OAuth token is stored only on the owner's workstation. Access can be revoked at any time from Google Account → Third-party connections. Revoking access stops all Drive access immediately.

Contact

Questions about this policy can be sent to the support email address shown on the app's Google sign-in consent screen.
