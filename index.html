batch_testbed

batch_testbed is a private, single-user tool for batch image-generation testing. It is not a public service and is not offered to anyone other than its owner.

What it does

  • Watches one Google Drive folder chosen by its owner for task folders and a ready flag file.
  • Downloads the task's prompts and input images, generates images with image-generation models, and uploads the results back to the same folder.

Google account access

The app asks for Google Drive access only so it can read and write files in its owner's own task folder. It does not access any other Google service.

See the privacy policy for details.
